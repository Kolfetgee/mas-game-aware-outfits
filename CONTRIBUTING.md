# Contributing and reporting issues

This repository documents an experimental, unreleased MAS submod. Public code contributions are not open until the maintainer has finished the source and licensing readiness review.

When discussing a bug, mention the MAS/Ren'Py version, Windows version, whether the issue occurs on game start or exit, whether clothing and hairstyle were restored, and whether any other MAS scene was active. Please **redact personal data** from logs before attaching them.

Do not post official DDLC/MAS assets, fan spritepack contents, copyrighted music, screenshots containing nonredistributable art, or unreviewed AI-generated in-character content. Suggest improvements via issues when an issue tracker becomes available.

Development status and limitations are recorded in [docs/STATUS.md](docs/STATUS.md).
